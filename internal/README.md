# internal/

Application packages (Web-App Development Stack v2.0, Sections 6 and 7).

| Package | Responsibility |
|---|---|
| `config` | Loads and validates configuration; refuses to start when invalid |
| `database` | Opens connections (as the application role) and runs migrations |
| `dbgen` | Generated by sqlc from `db/queries` — never edit; run `make generate` |
| `auth` | Entra ID sign-in, server-side sessions, roles |
| `audit` | Append-only audit events, written in the same transaction as the change |
| `web` | Routes, middleware, handlers, template rendering |
| `items` | **Example domain** — the pattern to copy for each business area |
| `synth` | Synthetic data definitions |
| `testdb` | Disposable test databases built exactly like production |
| `requestid` | Request identifiers for logs, audit events, and error pages |
