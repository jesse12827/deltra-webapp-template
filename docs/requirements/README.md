# Requirements

Place the application's approved Software Requirements Specification here, for example
`Procurement_Software_Requirements_Specification_v1.0.md`, along with its source documents
(user guide, project overview) in a `sources/` subfolder.

Rules (Change Management Standard Sections 134A–134B; AI Policy Section 26A.4):

- The SRS changes only at the Approver's instruction. Agents propose changes in
  `docs/decisions/decision-log.md`, never by editing the SRS.
- Decisions the Approver ratifies at each Acceptance Gate are folded into the next SRS version.
