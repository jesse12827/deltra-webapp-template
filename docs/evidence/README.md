# Evidence packages

One folder per milestone, for example `docs/evidence/M1/`, containing:

- `evidence.md`, built from [`TEMPLATE.md`](TEMPLATE.md) (Change Management Standard Section 134B); and
- `reviews/`, holding each Reviewer Agent report, saved unchanged as `<agent>-<YYYY-MM-DD>.md`
  (Web-App Development Stack Section 18).

Agents assemble the package; the Approver reviews it at the Acceptance Gate and records the decision in it.
Evidence packages are retained under Change Management Standard Section 127. Do not delete them.
